      Ordem de inserção das disciplinas

      O que é

      As 134 disciplinas da FCTE (UnB Gama) de 2026.2, retiradas do SIGAA, são organizadas em três árvores binárias de busca, todas implementadas à mão em Python. O Python roda no navegador via Pyodide.

      AVL (1962) — chave: código

      Cada nó guarda sua altura. O fator de balanceamento (altura esq. − altura dir.) fica sempre em −1, 0 ou +1. Quando vira ±2, uma rotação simples (LL/RR) ou dupla (LR/RL) corrige. Altura ≤ 1,44·log₂ n.

      Rubro-Negra — chave: nome

      Os nós são vermelhos ou pretos. A raiz é preta, não há dois vermelhos seguidos e todo caminho tem o mesmo número de pretos. Altura ≤ 2·log₂(n+1). Faz menos rotações que a AVL e corrige muitos casos só recolorindo.

      BST simples

      Fica aqui para comparação: sem balanceamento, a entrada ordenada vira uma lista de altura n.
